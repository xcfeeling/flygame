# 云岭航线 · 离线模拟飞行

一个完全离线运行的单机模拟飞行游戏，基于 Three.js 和原生 JavaScript。重点是把真实客机的**冷舱启动、四发管理、地面滑行、起飞、进近、着陆与复飞**做成可操作的完整流程，并用真实参数决定不同操作的结果。

当前默认机型为 **波音 747-400**，同时提供 **波音 747-8F** 供选择；底层已经按“多机型参数表”架构实现，后续可继续加入其他客机或直升机。

```
双击 启动游戏.bat   →   浏览器打开 index.html   →   开始飞行
```

不需要联网、不需要安装 Node.js 也能直接玩；仓库中的 `dist/game.js` 是已经构建好的离线产物。

## 游戏特点

- **真实冷舱流程**：主电瓶 → 外部电源 → 航空电子 → APU → APU 引气 → 电动泵 → 关闭 PACK → 发动机引气 → 四台发动机依次启动 → 四台发电机接入。顺序错误、无引气、PACK 未关、发电机未接入都会给出中文拒绝原因。
- **四发宽体机模拟**：四台发动机独立 N1/N2/EGT/燃油流量/反推/损坏/起火；四套发电机、电动泵、液压、防冰与地面扰流板逻辑。
- **完整飞行阶段**：冷舱、滑行、起飞、爬升、巡航、进近、着陆、复飞、脱离跑道和成绩结算。
- **真实参数驱动**：重量、燃油、襟翼档位、起飞速度、进近速度、下降率、风、跑道摩擦、超速和过载都会影响结果，而不是脚本动画。
- **多机型架构**：机型参数集中在 `src/sim/aircraftTypes.js`，外形、座舱和物理都按机型参数生成。
- **离线与单机**：无服务器、无账号、无网络请求；存档和设置保存在浏览器本地。
- **中文界面**：中文检查单、无线电字幕、告警、教程和完整按键总览。

## 机型与选择

标题页提供“选择飞机”区域：

| 机型 | 发动机 | 典型参数 | 说明 |
| --- | --- | --- | --- |
| **B747-400** | 4 × CF6-80C2 | 长 70.6 m / 翼展 64.4 m / MTOW 396.9 t | 默认机型，经典四发宽体客机 |
| **B747-8F** | 4 × GEnx-2B67 | 长 76.3 m / 翼展 68.5 m / MTOW 447.7 t | 加长货运型，参数与外形不同 |
| 轻型直升机 / 其他机型 | — | — | 预留扩展位，后续加入 |

切换机型会重建飞机外形、驾驶舱和飞行参数；存档会记录机型，继续飞行时自动恢复。

## 快速开始

### 方式一：直接玩（推荐）

1. 下载或克隆本仓库。
2. 双击根目录的 **`启动游戏.bat`**（或直接双击 `index.html`）。
3. 浏览器打开标题页后，先选机型，再选择情景：
   - **冷舱启动**：从停机位开始，完整走一遍通电、APU、四发启动和滑行。
   - **跑道起飞**：双发/四发已就绪，直接体验起飞、爬升和收轮收襟翼。
   - **五边进近**：从五边开始，练习稳定进近、拉平着陆或复飞。

> 建议使用 Chrome / Edge 等支持 WebGL 的浏览器。首次点击或按键后音频才会启用，这是浏览器的自动播放限制。

### 方式二：从源码构建

```bash
npm install
npm run build      # 生成 dist/game.js
npm run build:dev  # 开发构建（带 sourcemap）
```

构建后仍然只需要打开 `index.html`，不需要本地服务器。

## 飞行流程

### 冷舱启动

1. 接通主电瓶、外部电源、航空电子。
2. 启动 APU，等 APU 可用后接通 APU 引气。
3. 接通 1 号电动泵，关闭 PACK，启动 ENG1，接入 GEN1。
4. 接通发动机引气，依次启动 ENG2 / ENG3 / ENG4 并接入对应发电机。
5. 设置起飞襟翼 10°，松开停留刹车，滑行到 RWY36。

### 起飞

- 对准跑道中线，推力加到起飞档位。
- 达到机型 VR（B747-400 约 160 kt）时柔和抬轮。
- 建立正上升率后收轮，按计划收襟翼。

### 进近与着陆

- 起落架放下、襟翼 30°、扰流板预位。
- 保持约 VAPP 速度（B747-400 约 145 kt）和 3° 下滑道。
- 低高度下降率过大时立即复飞。
- 接地后扰流板自动展开，油门慢车可解锁反推；使用反推、机轮刹车减速并脱离跑道。

## 参数与结果判定

- **起飞性能**：重量越大、顺风越强，离地速度和滑跑距离越大；襟翼档位改变升力和阻力。
- **接地结果**：
  - 下降率 ≥ −2.2 m/s：正常着陆；
  - −2.2 ~ −3.6 m/s：硬着陆，起落架受损；
  - < −3.6 m/s：重着陆 / 结构损坏，任务失败。
- **复飞**：低高度下降率超过 −2.6 m/s 时自动触发复飞提示，建立正上升率后重新爬升。
- **超限**：襟翼/起落架超速、超过最大马赫数、过载超限、刹车过热都会造成持续损伤或警告。
- **特殊事件**：跑道冲出、跑道外接地、撞树、鸟击、发动机损坏和结构失效有独立结果。
- **评分**：综合下降率、接地点偏差、着陆滑跑距离、硬着陆次数、复飞次数、损伤和超重情况。

│  │  ├─ state.js           # 飞行状态结构

│  │  └─ save.js            # 本地安全存档
│  └─ view/

│     ├─ aircraft.js        # 747 外形与动画
│     ├─ cockpit.js         # 747 驾驶舱与仪表

## 开发与测试

需要 Node.js 18+（开发时使用 Node 24 验证）。

```bash
npm install

npm test          # Node 物理/系统/任务/存档测试
npm run build     # 生产构建
npm run build:dev # 开发构建（带 sourcemap）
npm run test:browser   # 真实 Chrome 浏览器集成测试
npm run test:all       # 单元测试 + 生产构建 + 浏览器测试
```

- 单元测试覆盖冷舱联锁、四发启动、四发反推、失速、正常/硬/重着陆、复飞、顺风、机型参数差异和存档。
- 浏览器测试覆盖机型选择、四发冷舱启动、起飞、正常着陆、反推、复飞、重着陆、油门键位、自由环视、滚轮缩放和离线 `file://` 启动。
- 浏览器测试使用 `playwright-core` 调用本机 Chrome/Edge，可设置环境变量 `CHROME_PATH` 指定浏览器路径。

## 已知限制

- 所有模型、纹理、音效均为程序化生成，属于模拟近似，不是用于训练的认证数据或 CAD 级模型。
- 目前只有 B747-400 与 B747-8F 两种可飞机型；直升机及其他机型为预留扩展位。
- 无联网对战、无 AI 空中交通、无完整 FMS/自动着陆。
- 机场为单跑道教学场景（RWY36/18）；地形和建筑为程序化生成。
- 冷舱情景从停机位开始，滑行到跑道需要几分钟；想快速体验请选“跑道起飞”或“五边进近”。
